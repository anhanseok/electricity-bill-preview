# 우리집 전기요금 미리보기

이번 달 전기요금이 얼마 나올지 청구서 전에 미리 알려주는 시험 서비스입니다.
대학 수업(2026년 2학기) 프로젝트로 개발 중이며, 개발자 본인의 가족 1가구만 이용합니다.

- 서비스업체: 8번아이언
- 데이터 출처: 한국전력 Open P-Meter API (명의자가 EDS에서 정보제공에 동의한 경우에만)
- 문의: [Issues](https://github.com/anhanseok/electricity-bill-preview/issues)

---

## 사용절차 — 서비스 소개

대학 수업 프로젝트로 만드는 시험 서비스입니다.
개발자 본인의 가족 1가구만 이용합니다.
15분 단위 전기 사용량을 받아서 이번 달 예상 전기요금을 계산합니다.
누진 3단계에 가까워지면 미리 알려줍니다.

## 사용절차 — 이용 절차

1. 전기요금 명의자가 한전 EDS(전력데이터 서비스 마켓)에 회원가입합니다.
2. EDS에서 본인 고객번호를 등록합니다.
3. EDS에서 '우리집 전기요금 미리보기' 서비스를 찾습니다.
4. 서비스 약관(개인정보 수집 및 제3자 정보제공)을 읽고 동의합니다.
5. 동의가 끝나면 서비스가 Open P-Meter API로 고객정보와 전력 사용량을 받아옵니다.
6. 명의자는 서비스 화면에서 이번 달 예상 요금과 누진 단계를 확인합니다.
7. 사용량이 누진 3단계 기준의 80%에 닿으면 알림을 받습니다.

## 사용절차 — 받는 정보와 쓰는 곳

| API | 쓰는 곳 |
| --- | --- |
| 고객정보 | 정기검침일로 요금 계산 기간을 정하고 AMI 계기인지 확인 |
| 고객번호, 계기번호 / 고객번호 | 계약종별과 저압·고압 구분으로 적용할 누진 요금표를 정함 |
| 청구정보 | 지난달 실제 청구요금과 예상 요금을 비교해 계산이 맞는지 확인 |
| 15분단위 전력소비 데이터 | 최근 사용량을 보고 누진 구간에 가까워지면 알림 |
| 일단위 전력소비 데이터 | 하루 사용량을 더해 이번 달 누적 사용량과 예상 요금 계산 |

- 위 목적 말고 다른 곳에는 쓰지 않습니다.
- 다른 사람이나 다른 업체에 주거나 팔지 않습니다.
- 보유 기간은 동의일부터 1년입니다. 기간이 끝나면 받은 데이터를 지웁니다.

## 사용절차 — 동의 철회

명의자가 한전 EDS에서 정보제공 동의를 해지하면 그때부터 데이터를 받지 않습니다.
해지 전에 받은 데이터도 문의처로 요청하면 지웁니다.

---

## 메뉴얼 — 1. 시작하기

- 서비스 주소: https://github.com/anhanseok/electricity-bill-preview
- 처음 들어가면 한전 EDS 정보제공 동의를 했는지 확인합니다.
- 동의하지 않았으면 EDS로 가는 안내가 나옵니다.

## 메뉴얼 — 2. 메인 화면

| 항목 | 내용 |
| --- | --- |
| 이번 달 누적 사용량 | 정기검침일부터 오늘까지 쓴 전기량(kWh) |
| 이번 달 예상 요금 | 지금 속도로 쓰면 다음 검침일까지 나올 요금 |
| 누진 단계 | 지금 몇 단계인지, 다음 단계까지 몇 kWh 남았는지 |
| 계산 기준 | 계산에 쓴 정기검침일과 요금표 |

## 메뉴얼 — 3. 알림

- 이번 달 사용량이 누진 3단계 기준의 80%에 닿으면 알림을 보냅니다.
- 알림은 한 달에 한 번만 보냅니다.

## 메뉴얼 — 4. 지난달 확인

- 지난달 실제 청구요금과 서비스가 계산한 요금을 나란히 보여줍니다.
- 차이가 크면 계산 기준을 고치는 데 씁니다.

## 메뉴얼 — 5. 이용 중지

- 한전 EDS에서 정보제공 동의를 해지하면 이용이 중지됩니다.
- 받은 데이터를 지우고 싶으면 문의처로 요청합니다.
